# Fonctions avancées de Sangus

Sangus, pour servir dans vos tâches :  
Votre IA locale open-source pour générer, tester, corriger, structurer, et apprendre !

## Ce que Sangus sait faire :

- **Génération de code source**  
  Demandez-lui : “Crée-moi une API REST Flask”, “Écris un script Python qui trie des fichiers”, “Génère un composant React…”

- **Tests automatiques**  
  “Écris les tests unitaires pour ce module”, “Génère un test de validation pour cette fonction…”

- **Correction d’erreurs**  
  Copiez-collez une erreur : Sangus propose un diagnostic et une correction, avec explication.

- **Structuration de l’architecture**  
  “Propose une architecture pour une app e-commerce”, “Organise un projet Python modulaire…”

- **Tutoriels et guides**  
  “Explique-moi le pattern MVC”, “Donne-moi un tutoriel pour débuter avec FastAPI…”

- **Suggestions IA**  
  Refactoring, optimisation, conseils de sécurité, bonnes pratiques, extensions possibles…

## Comment ça marche ?

- Chat contextuel, édition de fichiers, actions IA (boutons rapides sur le code, suggestions en temps réel)
- Sélection du modèle IA : Ollama (local, ex: Llama3, CodeLlama…) ou OpenAI (gpt-3.5, gpt-4)
- Aucun abonnement, aucune limite : tout le pouvoir de l’IA sur votre machine, à votre service seul·e.

---

**Exemples d’utilisation** :

- “Corrige ce code et explique-moi l’erreur”
- “Ajoute la gestion des utilisateurs dans ce projet”
- “Génère la structure d’un projet React Redux complet”
- “Fais-moi un tutoriel sur les décorateurs Python”
- “Optimise ce script pour la vitesse”
